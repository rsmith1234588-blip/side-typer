What it does

Everything runs in the Side Panel, so it stays put while you work in the tab.

Real keystrokes

Sends trusted key events, so it works in editors that ignore pasted or scripted input.

Speed from 10 to 1,000 WPM

Set the pace with a slider and optionally vary the delay between keys.

Pause, resume, stop

Keeps its place. It pauses on its own if you switch tabs or the page navigates.

Code-editor friendly

Optionally skips leading indentation after line breaks, for editors that auto-indent.

Progress and time left

A progress bar, character count, and estimated time remaining.

Remembers your text

Text and settings are kept locally between sessions. Nothing is sent anywhere.

Install in about a minute

The extension isn't in the Chrome Web Store, so you load it yourself.

  1. Download the ZIP and unzip it.You'll get a folder called side-panel-typer. Keep it somewhere it won't be deleted; Chrome loads the extension from it.
  2. Open chrome://extensions.Type it into the address bar, or go to Menu → Extensions → Manage Extensions.
  3. Turn on Developer mode.The switch is in the top-right corner of the Extensions page.
  4. Click “Load unpacked” and choose the side-panel-typer folder.Select the folder that contains manifest.json, not the ZIP.
  5. Pin it and click the icon.The Side Panel opens. Paste your text, click into the field on the page, then press Start.

Questions

Common things people run into.

Why does Chrome say “started debugging this browser”?

The extension uses Chrome's debugger API to send keystrokes that pages treat as real typing. Chrome shows that banner whenever an extension does this. It goes away when typing stops. Closing the banner stops typing.

What permissions does it need?

sidePanel to show its controls, and debugger to send keystrokes to the active tab. It only attaches while you're typing and detaches as soon as you stop.

It won't type on some pages.

Chrome doesn't allow extensions to control its own pages, such as chrome:// pages or the Chrome Web Store. Try a regular website.

Does it work in Edge, Brave or other browsers?

It should work in Chromium-based browsers that support the Side Panel API (Chrome 116+). Firefox and Safari aren't supported.

How do I update it?

Download the new ZIP, replace the contents of your folder, then click the reload icon on the extension's card in chrome://extensions.
